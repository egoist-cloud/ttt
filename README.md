# Quantum — бот клана TALENT (cs2red)

Готовая версия. Заливать в GitHub можно **всё содержимое этой папки целиком**.

## Что обязательно должно лежать рядом с `script.py`

| Файл | Без него что будет |
|---|---|
| `ai_rules.py` | не работает ИИ, вопросы по правилам и разбор ошибок |
| `github_sync.py` | не работает сохранение привязок в GitHub |
| `requirements.txt` | Render не установит зависимости |
| `links.json` | пропадут все привязки Discord↔Steam |
| `players_db.json` | пропадут профили игроков |
| `users_db.json`, `moderators.json`, `votes.json`, `seen.json` | пропадут запреты, доступы, голосования, трекер активности |
| `rules.txt` | бот не будет знать пункты правил (создать из `rules.example.txt`) |

## Что можно не заливать

| Файл | Почему |
|---|---|
| `mass_links.json.bak` | резервная копия сломанного файла, боту не нужна |
| `diag_*.py` (17 файлов) | скрипты-разведчики cs2red, нужны только для отладки |
| `check.py`, `fix_json.py` | ремонт JSON руками, бот их не использует |
| `requirements-dev.txt` | `requests` для `diag_*.py`, боту не нужен |
| `PANEL-DEPLOY.md` | старая инструкция для панели Pterodactyl |

## Документы

- **`RENDER-ENV.md`** — что поменять в Render (переменные, диск, сервис)
- **`DEPLOY-RENDER.md`** — как деплоить, что проверить после запуска
- **`.env.example`** — все переменные с пояснениями (это шаблон, бот его не читает)

## Быстрый старт после деплоя

1. В логах Render должно быть: `🤖 ИИ`, `📚 Правила`, `✅ Команд синхронизировано: 24`.
2. В Discord: `/ping`, `/health`, `/rules 2.2`.
3. Один раз написать `!setup` в канале заявок — больше не потребуется.
4. Положить `rules.txt` в папку данных (`/data`) и выполнить `!ai_scan`.

## Команды

- Заявки: меню «выбрать клан» → модальное окно → голосование. Заместители (`DEPUTY_ROLE_ID`, можно несколько ролей через запятую) закрывают заявку **одним** нажатием.
- Привязка: `/link` + `/link_confirm` (подтверждение владения Steam), `/unlink`
- Модерация: `/admlink`, `/admunlink`, `/give`, `/take`, `/moders`
- Игроки: `/lookup`, `/player_info`, `/activity_show`, `/activity_all`
- ИИ: `/rules`, `/ask`, `/ai_status`, `!rules`, `!ask`, `!ai_status`, `!ai_scan`
- Диагностика: `/ping`, `!ping`, `/health`
