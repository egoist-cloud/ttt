# 🎮 Деплой бота на бесплатную панель для Discord-ботов (24/7, без карты)

Подходит для панелей на движке **Pterodactyl**: Kerit Cloud, FoxNetwork, Darkless Cloud,
RavenHost, AutoDisc и подобных. Схема действий у всех примерно одна.

> ⚠️ Перед началом: **перевыпусти токен Discord** (Developer Portal → Bot → Reset Token) —
> старый засветился в переписке. И **останови бота на ПК**: работать должен только один экземпляр.

---

## Что в архиве `quantum-bot-panel.zip`

```
script.py            — сам бот
requirements.txt     — зависимости
.env.example         — шаблон настроек (секретов внутри НЕТ)
links.json           — привязки Discord↔Steam (текущая база)
players_db.json      — профили игроков
mass_links.json      — массовая привязка
moderators.json      — доступ к командам
users_db.json        — запреты на заявки
votes.json           — голоса по заявкам
seen.json            — трекер активности
PANEL-DEPLOY.md      — эта инструкция
```

Файла `.env` в архиве **нет** намеренно — секреты создаёшь на панели сам (шаг 4).

---

## Шаг 1. Зарегистрироваться на панели

Зайди на сайт выбранной панели (например, **kerit.cloud**). Обычно порядок такой:
1. Вступаешь в их Discord-сервер (там выдаётся ссылка на панель).
2. Регистрируешь аккаунт на панели. **Карта не требуется.**
3. Бесплатный план: ~256 МБ ОЗУ, ~2 ГБ диска, режим «без сна» (24/7).

## Шаг 2. Создать сервер

- Тип: **Discord bot / Python**.
- Тариф: **Free**.
- Регион: любой ближе к тебе (например, Германия).

## Шаг 3. Загрузить файлы

1. Открой **File Manager** (файловый менеджер) сервера.
2. Загрузи **содержимое** архива (распакуй zip заранее) в **корень** сервера.
3. Проверь: `script.py` и `requirements.txt` лежат прямо в корне, **не** во вложенной папке.

## Шаг 4. Создать `.env` (секреты)

1. В File Manager: **New File** → имя `.env`.
2. Открой его на редактирование и вставь:

```
DISCORD_TOKEN=<НОВЫЙ токен Discord>
GUILD_ID=1236663962893025411
ALLOWED_ROLE_ID=1396606001188175922
AUTO_ROLE_ID=1448368118190837800
BYPASS_ROLE_ID=1447953701787406368
SPAM_VOTE_ROLE_ID=1396606001188175922
CLAN_NAME=TALENT
CLAN_URL=https://cs2red.ru/clans/id/47
STEAM_API_KEY=<твой ключ>
CS2RED_TOKEN=<cookie token>
CS2RED_BH=<cookie bh>
CS2RED_YASC=<cookie _yasc>
CS2RED_BROWSER_ID=<cookie browser_id>
CS2RED_YANDEXUID=<cookie yandexuid>
```

> `DATA_DIR` указывать **не нужно** — по умолчанию данные пишутся рядом со скриптом (корень сервера),
> а он на панели сохраняется между перезапусками.

## Шаг 5. Установить зависимости

Открой **Console** и выполни:

```
pip install -r requirements.txt
```

(если `pip` не найден — `python3 -m pip install -r requirements.txt`).
Дождись установки `discord.py`, `aiohttp`, `python-dotenv`.

## Шаг 6. Запуск

- В настройках сервера (**Startup**) укажи команду запуска: `python3 script.py`
- Нажми **Start**.

## Шаг 7. Проверка

- В консоли должно появиться: `✅ Бот ... готов!` и `✅ Синхронизировано команд: N`.
- Бот онлайн в Discord, команды отвечают.
- **Останови бота на своём ПК**, чтобы не было двух экземпляров.

---

## Как обновлять в будущем

1. Правишь код локально в PyCharm.
2. В File Manager панели заменяешь изменённый файл (например, `script.py`).
3. Нажимаешь **Restart**.

Данные (JSON) лежат рядом со скриптом и не теряются при перезапуске.

---

## Если что-то не так

- **Бота убили из-за памяти (OOM / Killed)** → на free-плане 256 МБ может не хватить.
  Возьми панель с 512 МБ+ или вернись к Amvera (290 ₽/мес).
- **Не найден модуль discord** → не выполнен шаг 5 (`pip install -r requirements.txt`).
- **Бот оффлайн, в логах ошибка токена** → проверь, что в `.env` стоит **новый** `DISCORD_TOKEN`.
- **Данные пропали** → файлы JSON должны лежать в корне рядом с `script.py` (шаг 3).
- **Два бота отвечают** → останови локальный экземпляр.
